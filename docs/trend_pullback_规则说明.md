# trend_pullback：大周期定势 · 缩量回踩低吸 — 策略规则说明

> 源：用户口述交易系统（2026-09-03）。本文把自然语言逐条翻译为**可执行、可验证**
> 的量化条件，并逐条标注「原文直接可译 / 量化假设」。最终实现见
> `src/strategylab/engine/strategies/trend_pullback.py`，参数默认值见

**一句话总纲（原文）**：大周期定方向，20日线定趋势，缩量回踩找买点，放量上涨拿波段，破线放量立刻走。

## 一、大周期定方向（周线门控）—— 不满足直接放弃，不参与

| 原文要求 | 量化实现 | 类型 |
|---|---|---|
| 周线、月线趋势走平 / 回升 | 周线 MA20（≈100 交易日）与周线 MA30（≈150 交易日，近似月线）近 **4 周**变化率均 ≥ **-0.5%**（`flat_tol`，即允许小幅下倾 = “走平”） | 量化假设 |
| 杜绝下降趋势反弹 | 上述斜率不达标 → `major_ok=False`，**当日禁止一切买入**；持仓中该信号转坏 → 立即清仓（“大周期转坏”） | 直接可译 |
| 只做趋势反转 / 横盘打底 | 要求周收盘站上周线 MA20（`require_above_fast=true`），价格不处于中期均线之下的下降通道 | 量化假设 |

**说明**：月线未单独取月线周期，用周线 MA30 近似月线级趋势，避免在月线数据不足时提前失效。
每日信号落地时读取**最近一根已收盘周线**的状态（`merge_asof` 向后对齐，无未来函数）。

### 通道 A —— 趋势启动买点（主升初期）【原文第 1 条】

|---|---|---|

## 五、主力洗盘逻辑的近似处理【原文第四节】

原文“均线完好、趋势没坏；盘中剧烈震荡吓散户；缩量砸盘、假破位”本质是**不要被盘中波动
洗下车**。日线无法识别盘中破位，近似为：

- 只要 **MA20 拐头向上且未放量跌破**，就不主动卖出 —— 缩量假破位会被“破线+放量”双条件拦下；
- ⚠️ “盘中剧烈震荡”需要分钟级数据，**本策略不识别**（在局限中披露）。

## 六、止损 / 止盈（配套波段）【原文第六节】

| 原文 | 量化实现 | 适用 |
|---|---|---|
| 趋势票：20 日线有效跌破 + 放量 → 无条件止损 | `收盘 < MA20` **且** `量 ≥ 1.0×量均` 当日收盘卖出 | 非低位分型持仓 |
| 小票反弹：破 10 日线收不回 → 直接走 | `收盘 < MA10` 当日收盘卖出 | 低位分型持仓 |
| MA5 死叉 MA20 | 趋势走坏，收盘卖出 | 全部持仓（可开关） |
| 首次放量拉升不跑 | 只有浮盈 ≥ 8% 后才允许触发止盈 | —— |
| 连续爆量、高位滞涨、长上影 → 分批止盈 | 量 ≥2.0×量均 且（上影/全幅 ≥45% 或收平/收跌）且浮盈 ≥8% → **卖 50%**，余仓继续 | 可关 |
| 不贪主升末端鱼尾 | 剩余仓位由破线/死叉/大周期转坏接管，不设“必达目标价” | 直接可译 |
| 大周期转坏 | 周线门控翻空即清仓 | 策略兜底 |

执行顺序（同一日多信号冲突时）：**出货 > 分批止盈 > 硬止损 > 死叉 > 大周期转坏**。
盘中触及顺序无法从日线区分，全部以**收盘确认**成交（项目既有口径，见局限）。

## 七、执行口径与已知局限

- **执行价**：当日信号 + 当日收盘成交（沿用 strategy_lab 现有策略统一口径）。
  ⚠️ 严格意义上这是“用收盘价确认、用收盘价成交”的同日成交模型，存在轻微 look-ahead；
  与“次日开盘成交”相比，回测结果更乐观，实盘滑点成本更高。若需要更保守口径可在
  toml 增加 execution 开关（本版未实现）。
- **交易成本**：佣金 0.03% 双边、印花税 0.05% 卖方、沪市过户费默认 0（可开）、整手 100 股；
  由 `trading_cost.py` 统一收取，PnL 为净额。
- **T+1**：当日买入当日不卖出，自然满足。
- **前复权 qfq**：指标在 qfq 价格上计算，避免除权跳空污染均线。
- **局限盲区**（非行情可判，务必知晓）：
  1. “无持续减持利空”未实现（需公告/股东/龙虎榜数据）；
  2. “盘中洗盘/假破位”未识别（日线粒度）；
  3. “强庄”“筹码集中”是用振幅+涨停记忆的**代理指标**，会漏掉慢牛型庄股、误伤新股；
  4. 区间振幅 `最高/最低` 是窗口内极差，不保证“先涨后跌”方向性，2020 年上市的次新股
     前一年天然振幅巨大易被标为强庄。
- **过热环境失效**：该策略本质是**顺势+低吸**，在单边快熊或阴跌不止、以及 20 日线反复
  缠绕的横盘尾部最容易反复止损；参数（`turn_up_days`、`pullback_vol`、`stop_vol`、
  `tp_vol_blowoff`）存在过拟合风险，跨标的/跨年份稳定性需用多标的横截面对比检验。
