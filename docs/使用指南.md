# Strategy Lab 使用指南（手把手版）

> 这份指南写给**完全不懂编程、但想自己跑回测**的朋友。照着一步步做就行，所有命令都可以直接复制粘贴。
> 如果遇到看不懂的报错，直接跳到文末「常见问题」一节，大概率能找到答案。

---

## 0. 一句话先说清楚

这个项目能让你**输入一只股票 + 一段日期，自动跑出一份「策略回测报告」**：权益曲线、最大回撤、每笔买卖、夏普比率……并以网页形式打开看。
整个过程**默认什么都不用配置**就能跑（结果存在本地数据库，不需要你装数据库）。

---

## 1. 它能帮你做什么（大白话）

- **回测**：把一条已经验证过的交易策略，套到历史行情上，看看「如果当年照这个策略买卖，能赚/亏多少」。
- **换标的**：今天看 600216（浙江医药），明天看 002001（新和成），改个代码就行。
- **换区间**：想看 2020–2024，还是 2023 一整年，改日期就行。
- **换策略**：策略参数（底仓金额、阈值等）全写在配置文件里，改数字即可，不用碰代码。
- **对比**：把多次回测结果放在一起比，看哪个更好。不同本金会自动「归一化到 100」再叠加，公平可比。

> ⚠️ 重要：所有结果都是**程序基于历史数据算出来的，仅供研究参考，不构成任何投资建议**。

## 2. 开始前你要准备什么

| 要准备的东西 | 说明 | 难度 |
|---|---|---|
| 一台电脑（Windows / macOS / Linux 均可） | 能正常开机上网即可 | 无 |
| 能联网一次 | 第一次跑某只股票时需要联网取行情；之后可离线 | 无 |
| 安装 Python 3.11 或更高版本 | 一次性安装，后面会教 | ★☆☆ |

> 不需要你装数据库、不需要你会写代码、不需要你懂 K 线也能先跑通看个热闹。

## 3. 第一步：安装 Python

### 3.1 下载
- 打开官网 <https://www.python.org/downloads/> ，点那个最大的黄色按钮下载。
- **Windows 用户特别注意**：安装时务必勾选 **「Add python.exe to PATH」**（添加到环境变量），否则后面命令会找不到 Python。

### 3.2 验证安装成功
装完后，打开「命令提示符（CMD）」或「终端（Terminal）」，输入：

```bash
python --version
```

如果看到类似 `Python 3.11.x` 或 `Python 3.13.x` 的字样，说明装好了。
（如果提示「找不到命令」，大概率是 3.1 里那个 PATH 没勾选，重装一次勾上即可。）

> macOS 用户如果系统自带了旧版 Python 3.9，请务必从官网装一个 3.11+ 的版本，否则可能跑不起来。

## 4. 第二步：拿到项目代码

两种方式任选其一：

**方式 A：用 Git 下载（推荐，方便后续更新）**
```bash
git clone <项目仓库地址>
cd strategy_lab

（`git` 没装的话去 <https://git-scm.com/> 装一个，一路下一步即可。）

**方式 B：直接下载压缩包**

- 打开终端，`cd` 进解压出来的 `strategy_lab` 目录。

> 后面所有命令都**默认你已经 `cd` 进 `strategy_lab` 这个目录里了**。如果不确定，先 `cd` 进去再执行。

## 5. 第三步：安装依赖（只需一次）

在 `strategy_lab` 目录下，执行：

```bash
pip install -e .
```

这一步会把项目及所需库（pandas、numpy、sqlalchemy 等）装好，并生成两个命令：`strategylab`（命令行）和 `strategylab-web`（网页服务）。

- **如果提示 `pip` 找不到**：试试 `python -m pip install -e .`。
- **如果下载很慢/超时**：可以临时用国内镜像，例如：
  ```bash
  pip install -e . -i https://pypi.tuna.tsinghua.edu.cn/simple
  ```
- **看到 `Successfully installed strategylab-...`** 就说明成功了。

> ⚠️ **这步非常重要，不能跳过！** 后面的 `strategylab` 和 `strategylab-web` 命令**不是系统自带的**——只有跑完 `pip install -e .` 才会生成。如果跳过这一步直接打 `strategylab-web`，会报错 `'strategylab-web' is not recognized`（详见 FAQ Q1）。

> 💡 **如果装完了还是提示找不到命令**（常见于 Windows PowerShell / 部分终端）：这是 PATH 环境变量的问题，不影响使用。直接用以下写法，效果完全一样：
> ```bash
> python -m strategylab          # 等于 strategylab
> python -m strategylab.web      # 等于 strategylab-web
> ```

> ⚠️ **`python -m strategylab` 也报 `No module named 'strategylab'`？**  
> 这说明你**既没装包，也没告诉 Python 去哪找代码**。这个项目用了 `src/` 布局（代码在 `src/strategylab/` 里），Python 默认不会进去搜。两种修法任选其一：
> ```bash
> pip install -e .               # 推荐：一劳永逸，同时生成 strategylab / strategylab-web 命令
> ```
> 或者如果不想装包，临时告诉 Python 代码在哪（**每次打开新终端都要重设**）：
> ```bash
> # PowerShell（你当前用的）：
> $env:PYTHONPATH = "src"
> python -m strategylab.web
>
> # CMD：
> set PYTHONPATH=src
> python -m strategylab.web
> ```
> 建议直接 `pip install -e .`，以后就再也不用管 PYTHONPATH 了。

## 6. 第四步：配置「数据库」（新手可跳过！）

**默认什么都不用做。** 项目内置 SQLite（一个本地文件数据库），零配置开箱即用，结果会自动存到 `strategy_lab.db` 文件里。

只有当你**想用 MySQL / PostgreSQL**（比如多人共享、或数据量大）时才需要配置，见下方「进阶」。

### 进阶：用 MySQL（可选）
1. 先连上你的 MySQL，执行这一句建一个空库（**注意：程序只会建「表」，不会建「库」本身**）：
   ```sql
   CREATE DATABASE strategylab CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   ```
2. 在项目根目录新建一个文件，命名为 **`.env`**（注意开头有个点），内容写：
   ```
   DATABASE_URL=mysql+pymysql://你的账号:你的密码@数据库地址:3306/strategylab
   ```
   例如账号密码都是 `root`、数据库在本机：
   ```
   DATABASE_URL=mysql+pymysql://root:root@localhost:3306/strategylab
   ```
3. 保存。之后程序启动时就会自动连这个库，表会在第一次跑回测时自动建好。

> `.env` 文件已经写进 `.gitignore`，不会被提交出去，放心放账号密码（仅限你自己的机器）。

## 7. 第五步：准备行情数据

**你不需要手动准备。** 第一次对某只股票跑回测时，程序会联网从东方财富自动取行情并缓存到 `data/` 目录；之后再用同一只股票就直接读缓存，**不用重复联网、可以纯离线跑**。

缓存文件长这样（在 `data/` 里，普通用户不用管）：
- `600216_sh_daily.csv` —— 日线行情
- `600216_sh_weekly.csv` —— 周线行情

> 想强制重新取数？删掉 `data/` 里对应的 CSV 再跑即可。

## 8. 方式一：命令行回测（最简单）

在 `strategy_lab` 目录下，复制下面这行命令，改掉股票代码和日期就能跑：

```bash
# 如果安装了项目，直接用命令
strategylab --symbols 600216.sh --start 2023-01-01 --end 2024-12-31

# 如果提示找不到命令，用这个代替（效果完全一样）
python -m strategylab --symbols 600216.sh --start 2023-01-01 --end 2024-12-31
```

跑完会告诉你：总收益、年化、最大回撤、夏普、胜率、交易笔数，以及一个 `run_id`（这次回测的编号，存在数据库里）。

> 💡 后面所有 `strategylab` 命令都可以直接替换成 `python -m strategylab` 来跑，参数不用改。

### 常用变形（直接复制改）

**一次对比多只股票：**
```bash
strategylab --symbols 600216.sh 300765.sz 002001.sz --start 2023-01-01 --end 2024-12-31
```

**看有哪些策略可用：**
```bash
strategylab --list-strategies
```

**看数据库里已经存了哪些回测历史：**
```bash
strategylab --list-runs
```

### 参数说明表

| 参数 | 必填 | 作用 | 例子 |
|---|---|---|---|
| `--symbols` | ✅ | 股票代码，可多个，空格隔开 | `600216.sh` 或 `600216.SH` 或 `sh600216` 都行 |
| `--start` | ✅ | 回测开始日期 | `2023-01-01` |
| `--end` | ✅ | 回测结束日期 | `2024-12-31` |
| `--strategy` | | 策略配置，默认内置 `kdj_macd_dual_entry` | `--strategy my.toml` |
| `--names` | | 展示用的名字（可选） | `--names 浙江医药` |
| `--out` | | 输出目录，默认 `data/` | `--out ./out` |
| `--list-strategies` | | 只列出可用策略就退出 | — |
| `--list-runs` | | 只列出历史回测就退出 | — |

> 股票代码写法很宽松：`600216.SH` / `sh600216` / `600216sh` 都能识别。

## 9. 方式二：网页回测（最直观，推荐）

### 9.1 启动网页服务
在 `strategy_lab` 目录下执行：

```bash
# 如果安装了项目，直接用命令
strategylab-web

# 如果提示找不到命令，用这个代替（效果完全一样）
python -m strategylab.web
```

看到类似 `Serving HTTP on 127.0.0.1:8000` 的提示就成功了。**保持这个窗口开着**，不要关。

> 💡 想换端口（比如 8000 被占用）：
> ```bash
> PORT=9000 strategylab-web
> # 或
> PORT=9000 python -m strategylab.web
> ```

### 9.2 打开浏览器
打开浏览器，访问：<http://127.0.0.1:8000>

你会看到一个表单：
1. **标的**：在输入框里打字（比如「浙江」或「600216」），会**实时弹出候选股票**，点一下就填进去；支持多个（逗号/空格隔开）。
2. **开始 / 结束日期**：选回测区间，格式 `YYYY-MM-DD`。
3. **策略**：下拉框选一个（默认就有内置策略）。
4. 点 **「运行回测」** → 页面直接画出完整报告（权益曲线、回撤、每笔成交、指标表、策略说明）。
5. 想重跑？点左上角 **「← 新建回测」** 回到表单。

> 💡 **三种选标的方式**（可单独用，也可组合）：
> - **① 实时搜索**：输入框打字（「浙江」或「600216」），实时弹候选，点选填入（见上第 1 点）。
> - **② 按板块选股**：点「**按板块选股**」下拉，选一个**申万一级行业**（共 31 个，如半导体 / 白酒 / 化学制药）；选定后弹出该板块**成分股勾选面板**，勾选你要的股票（**单次最多 10 只**），点「✕ 全清」可一键清空。勾选结果会与搜索框里的标的合并进入回测。
> - **③ 直接输入**：支持逗号或空格分隔多个代码 / 名称。
>
> **标的显示规则**：界面上所有地方（搜索候选、已选标的、左侧历史、对比页标签、持仓明细）都**显示股票名称**（如「浙江医药」）而非代码；代码在后台默默对应，你完全不用记。

> 📅 **日期快捷按钮**：日期框旁有「**最近 1 年 / 最近 3 年 / 最近 5 年**」三个按钮，点一下自动填入对应起止日期（以今天为终点往前推），免去手填。

### 9.3 关闭网页服务
回到那个运行 `strategylab-web` 的窗口，按 `Ctrl + C` 即可停止。

## 10. 第六步：查看历史 & 跨回测对比

每次回测都会存进数据库。你可以把多次结果放在一起比：

1. 浏览器打开 <http://127.0.0.1:8000/history> （这就是「历史回测」页）。
2. 页面列出所有历史回测（按时间倒序），**勾选 2 个或以上**。
3. 点 **「跨回测对比」** → 生成对比报告：
   - **权益曲线**：每条曲线都**从 100 起步**（把你不同本金的回测公平归一化），方便直接叠加比较涨跌幅度。
   - **指标对比表**：各回测的总收益 / 年化 / 回撤 / 夏普 / 胜率 / 笔数并排展示（保留各自原始百分比）。
   - 每个回测还有独立标签页，含自己的权益图、指标表、合并持仓成交明细。

### 10.1 持仓明细表怎么看
点开某个回测的独立标签页，里面的「持仓明细」表把每笔**底仓**作为一行主记录，其下的**做 T** 子行缩进显示（同一持仓组内的多次高抛低吸）。关键列：

| 列 | 含义 |
|---|---|
| 持仓组 | 第几笔底仓（如 `#1`、`#2`…） |
| 方向 | 多 / 空 |
| 开仓日 / 平仓日 | 底仓买入 / 卖出日期 |
| 持有(天) | 底仓持有交易日数 |
| 底仓数量 | 底仓股数 |
| 建仓价 / 清仓价 | 底仓买入 / 卖出价 |
| 底仓盈亏 | 仅算底仓（不动做 T）的盈亏金额 |
| 做T笔数 | 该持仓组内做 T 次数 |
| 总收益 / 总收益率 | 底仓 + 做 T 合计 |
| **持仓不动收益率** | 假设建仓后**一直持有到清仓、期间完全不做 T** 的收益率（衡量「底仓本身」的盈利） |
| **T持有到清仓收益率** | 把做 T 也考虑进来、从建仓持有到清仓清掉的全部收益率（= 上面的总收益率，用于和「持仓不动」对比，直观看出做 T 是增厚还是拖累） |

> 对比「持仓不动收益率」与「T持有到清仓收益率」：两者之差就是**做 T 对这笔持仓的贡献**——正数说明做 T 增厚了收益，负数说明做 T 反而拖累。

> 小知识：为什么曲线都从 100 开始？因为 A 投入 10 万、B 投入 100 万，绝对值没法比；都折算成「起始 = 100」，比的就是「涨跌幅谁更强」。

## 10.5 v2.0 新功能：批量扫描与收益排名（数据生产页 / 分析查询页）

> v2.0 把工具从「一只一只选股回测」升级为「**选个策略，一键跑一批股票，看谁赚得多**」。
> 核心思路：**一次跑、多次查**——跑过的数据全存库，以后查询直接出结果，不重跑。
> 回测区间**固定为 2020-01-01 到今天**，你不用再选日期。

### 10.5.1 顶部导航
v2.0 起，网页顶部多了一条导航栏，四个入口：
- **首页/快速回测**（`/`）：就是原来的单次回测表单，想临时跑一两只时用。
- **数据生产**（`/production`）：批量跑数据用（见 10.5.2）。
- **分析查询**（`/analysis`）：看排名用（见 10.5.3）。
- **回测历史**（`/history`）：原来的历史对比页。

### 10.5.2 数据生产页（/production）—— 跑数据
**用途**：选一个策略 + 选一批股票，后台批量跑回测，跑完存库。

1. 打开 <http://127.0.0.1:8000/production>。
2. **选策略**：下拉选一个（默认「周线MACD + 日线KDJ 双入口做T」）。
3. **选范围**（三选一）：
   - **按板块**：勾选一个或多个申万一级行业（如「化学制药」「半导体」），系统会跑这些板块的**全部成分股**。
   - **自定义池**：手动输入或从板块勾选一批股票（最多 50 只）。
   - **全市场预热**：点一下，后台把 31 个板块、约 5500 只股票全部跑一遍（首次很慢，见下方说明）。
4. 点 **「开始扫描」** → 页面立刻返回一个 `batch_id`，后台开始跑。
5. **看进度**：页面每 2 秒刷新一次，显示「已完成 X / 总数 Y · 失败 Z · 跳过 W（命中复用）· 预计还剩 N 分钟 · 当前正在跑：浙江医药」。
6. 跑完显示 ✅，并提示「去分析查询页看排名」。
7. **板块总览**：页面下方有 31 个板块的小卡片，每个显示 ✅（全部跑完）/ ⏳（跑了一部分）/ 未跑，按「策略×板块」维度独立打钩。
8. 想中途停？点 **「取消」**，已跑完的保留，没跑的标记取消。

> 💡 **命中复用**：如果你之前已经用**同一个策略、同一只股票、同样的参数**跑过，系统会自动跳过（显示「跳过/命中」），不重复跑。所以第二次提交同样批次会秒级返回。**改了参数**（如调了底仓金额）才算新数据，会重跑。

> ⚠️ **全市场预热首次很慢**：约 5500 只股票首次取数 + 回测，即使 8 路并发也要 1-2 小时（取决于网络和东财限流）。建议在闲置时触发，中途可关浏览器（后台继续跑），之后回来用 `/production` 页或 `/api/batch` 查进度。中途服务被关，重启后该批次标记为「已中断」，可一键「重新发起」（自动复用已跑完的部分）。

### 10.5.3 分析查询页（/analysis）—— 看排名
**用途**：从已落库的数据里查排名，**不重跑**。

1. 打开 <http://127.0.0.1:8000/analysis>。
2. **选策略** + **选范围**（板块/池/全部已跑过的）——**不用选日期**（固定 2020-至今）。
3. 点 **「查询」** → 表格列出所有**已跑过的**股票，按**总收益率从高到低**排序：
   - 列：股票名称 · 总收益率 · 最大回撤 · 夏普比。
   - 顶部显示「共 N 只已跑过，还有 M 只未跑（去数据生产页发起）」。
   - 分页，每页 50 只。
4. **点某一行** → 新窗口打开该股票的完整回测详情仪表盘（权益曲线、持仓明细等，和原来一样）。
5. 想导出？点 **「导出 CSV」**（P2 功能）拿到 Excel 可打开的排名表。

> 💡 **只展示已落库的**：分析页只列出跑过的股票，干净快速。没跑过的不会出现在列表里（顶部会告诉你还差几只）。想跑未跑的，去数据生产页。

### 10.5.4 两个页面的关系
```
数据生产页 (/production) ──跑数据──→ 进度 ──完成──→ 引导去分析页
分析查询页 (/analysis) ──查排名──→ 点行 → 详情仪表盘
                       └→ 想跑未跑的 → 跳数据生产页
```
**简单记**：生产页负责「造数据」，分析页负责「用数据」。造一次，反复用。

## 11. 结果存在哪了？

回测结果**不再写 CSV/JSON 文件**，而是统一存入数据库：

- **命令行**：`strategylab --list-runs` 直接打印历史列表（含 run_id、标的、策略、区间）。
- **网页**：`/history` 页可视化查看与多选对比。
- 默认数据库是项目里的 `strategy_lab.db` 文件（SQLite）；配置 MySQL 后则在你的 MySQL 库里。

行情缓存（输入数据）仍在 `data/` 下的 CSV 里，那是另一回事——它们是「原料」，不是「结果」。

## 14. 常见问题（FAQ / 故障排查）

**Q1：`strategylab-web : The term 'strategylab-web' is not recognized as the name of a cmdlet, function, script file, or operable program.`（或「不是内部或外部命令」/ `command not found`）**

这是最常见的问题，原因是**没装项目**或者**PATH 环境变量不包含 Python 命令目录**。解决分三步：

1. **先确认你是在项目目录里**（`cd strategy_lab`）。不在的话先 `cd` 进去。
2. **确认执行过 `pip install -e .`** 且看到了 `Successfully installed strategylab-...`。没执行过的话跑一次（参考 §5）。
3. **如果已经装过了还是报错**（常见于 Windows PowerShell），直接用等价写法即可，参数和功能完全一样：
   ```bash
   python -m strategylab --symbols 600216.sh --start 2023-01-01 --end 2024-12-31
   python -m strategylab.web      # 启动网页服务
   ```
   用 `python -m strategylab` 代替 `strategylab`、`python -m strategylab.web` 代替 `strategylab-web` 就行了。

**Q2：`python -m strategylab.web` 报 `ModuleNotFoundError: No module named 'strategylab'`**
- 原因和 Q1 类似：这个项目用了 `src/` 布局，代码在 `src/strategylab/` 下，但 Python 默认不会去 `src/` 里找模块。
- 解决（二选一，推荐第一种）：
  1. `pip install -e .`（安装项目，一劳永逸，同时生成 `strategylab` / `strategylab-web` 命令）。
  2. 每次跑之前先设环境变量（仅本次终端有效）：
     ```bash
     # PowerShell
     $env:PYTHONPATH = "src"
     python -m strategylab.web

     # CMD
     set PYTHONPATH=src
     python -m strategylab.web
     ```

**Q3：网页打不开 / 提示无法连接**
- 确认 `strategylab-web` 那个窗口还开着（别关）。
- 浏览器地址是 `http://127.0.0.1:8000`（不是 `localhost` 也行，但 127.0.0.1 最稳）。
- 8000 端口被占用：换端口 `PORT=9000 strategylab-web`，然后访问 `http://127.0.0.1:9000`。

**Q4：报数据库连接错误**
- 默认 SQLite 不会连不上。若你配了 MySQL/PostgreSQL，检查 `.env` 里的 `DATABASE_URL` 账号密码地址端口是否正确，且那个空库（`strategylab`）已经 `CREATE DATABASE` 建好。

**Q5：行情取数失败 / 一直卡在取数**
- 第一次跑需要联网且能访问东方财富行情接口。公司网络/防火墙可能拦截，换网络或离线用已有 `data/` 缓存试试。
- 想强制重取：删掉 `data/` 里对应股票的 CSV。

**Q6：pip 安装很慢或超时**
- 用国内镜像：`pip install -e . -i https://pypi.tuna.tsinghua.edu.cn/simple`

**Q7：想彻底重来 / 清掉所有历史**
- 命令行历史：`strategylab --list-runs` 查看后，按需删除（见项目 技术文档 的删除接口说明）。
- 直接删数据库文件 `strategy_lab.db`（默认 SQLite 时）最彻底，下次跑会重建。

**Q8：结果文件在哪？为什么找不到 CSV？**
- 结果已经落库（数据库），不再生成 `*_equity.csv` / `*_trades.csv` 这类文件。要看结果用 `--list-runs` 或网页 `/history`。
- `data/` 下的 CSV 是**行情缓存（输入）**，不是回测结果。
