## 一、野村到底说了什么（观点梳理）

**1. 2026 年 A 股"三大分化"（年度策略，2026-01-09）**
- **行业分化**：科创利润持续挤占金融地产份额；
- **盈亏分化**：全 A 利润增长，但超半数公司利润增速下滑；
- **内外需分化**：海外营收占比 >20% 的企业，净利润贡献已超 25%。
- 上调沪深 300 2026/2027 净利润增速至 **+7.2% / +8.4%**（盈利驱动，非估值）；但**静态 PE 已处近十年均值 +1 倍标准差**，估值再扩张需超预期流动性或基本面修复。
- **三条主线**：① **智造出海**（AI 硬件、创新药、新能源、汽车、工程机械、军工）；② **审美出海**（入境游、短剧、文创潮玩、手游/主机游戏、新式茶饮）；③ **增量资金被动化**（平准基金 + 散户增持 ETF → 指数权重股边际流动性）。

**2. 中期策略（2026-06-17，"油价、通胀与 AI 革命"）**
- 短期：美债收益率走强 + 通胀韧性 + AI 高拥挤交易 → **全球波动放大、新兴市场承压**；近三周 A 股因交易因素快速调整。
- **短期防御**：用**红利**提升组合防御性，优先**资本金消耗有限、高 ROE/高股息的银行股**，以及受益供给端集中度提升的**央企地产龙头**。
- **中长期**：基准情形"高低切换"仅为短暂现象，**投资回报仍主要由科技主线贡献**；重点看**算力硬件**——受益 AI 需求扩张但仍受制于产能的**存储、光通信、AI 电源/液冷、燃气轮机**等算力基建配套，以及受益政策与高景气的**国产算力**。

## 二、与当前市场的交叉验证（关键洞察）

将野村框架叠加当前真实市场数据（2026-07-30），二者高度自洽：

| 维度 | 野村判断 | 当前市场实测 | 一致性 |
|---|---|---|---|
| 风格 | 短期红利防御、高低切换暂时 | 价值/大盘/防御主导，银行/白酒/油气领涨；成长/AI 不在榜单 | ✓ 吻合 |
| 估值 | 静态 PE 已 +1std，扩张需催化 | 中证全指 PE(TTM) 21.03，10 年分位 **86%** | ✓ 吻合 |
| 技术 | 科技近期快速调整 = 再配置窗口 | 寒武纪/工业富联**技术面深调**（月线 −30%~−42%），但基本面仍强（87–89） | ✓ 吻合 |
| 驱动 | 科技+周期是盈利改善核心 | 工业企业利润 +18.7%（有色+99%），与"周期+科技盈利驱动"一致 | ✓ 吻合 |

**结论**：野村眼中"短期防御、中长期科技"并非空谈，而是与当下市场结构一致。可落地的机会 = **现在拿野村也认可的红利防御（银行）做底仓，同时利用科技/出海主线技术面降温的"再配置窗口"分批布局**。

## 四、多空平衡

**看多（与野村共识）**
- 盈利驱动：沪深 300 净利 +7.2%/+8.4%，科技+周期盈利改善为核心驱动力。
- 科技主线长期逻辑未破：AI 算力需求扩张、国产替代、政策加持。
- 低利率（10Y 1.72%）+ 红利防御提供下行保护；再配置窗口已现（科技技术面深调）。

**看空 / 风险**
- 野村自身警示：**静态 PE 已 +1std**，估值扩张需超预期催化；**美债收益率/通胀韧性**压制新兴市场；**AI 高拥挤交易**波动大。
- 当前市场技术面弱（MACD 死叉、缩量），科技股虽基本面强但**估值贵**（寒武纪 211x），回调未必结束。
- 出口链（智造/审美出海）受**贸易摩擦与地缘**扰动；"反内卷"利润改善更多在 2027 才显现。

## 五、操作建议与评级

| 方向 | 建议 | 节奏 |
|---|---|---|
| 红利防御（银行） | **增持**（底仓） | 与当前主线重合，可逢回调加 |
| 算力硬件（工业富联/寒武纪） | **增持 / 谨慎增持** | 技术面降温中，**分批、不追高**，寒武纪仅限高风险偏好 |
| 智造出海（三一/恒瑞） | **增持** | 估值合理，可布局 |
| 审美出海 / 新能源 / 汽车 / 军工 | 方向性关注 | 待进一步筛选个股 |
| 纯题材（如前期江淮类） | 中性 | 仅短线，不列入核心 |

**组合思路**：以"红利银行（防御底仓）+ 智造出海（三一/恒瑞）+ 算力硬件（工业富联为主、寒武纪小仓）"构建，利用当前科技技术面降温的窗口分批建仓，等待野村所言"高低切换"回摆至科技主线。

> **风险提示**：野村观点为卖方研究判断，可能存在偏差；中证全指估值处历史高位、短期技术走弱，且海外利率/通胀与 AI 拥挤交易构成下行风险。任何判断均可能因宏观、政策、商品价格或外部冲击而失效。
