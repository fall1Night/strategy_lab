- 用户诉求：合集=策略名称+显示时间，子集=股票名称。
- 改动（software-team 快速模式：工程师+QA，QA 15/15 通过）：

  2. 子集 `.rec` 显示 `symbol_name`（仅空值回退 `symbol`、再空显示「—」）；保留收益率红绿 `rval pos/neg` + 跳转 /history。

- 已知问题（数据层遗留，非源码 bug）：极老 run 的 `symbol_name` 为空时，子集会回退显示代码（不影响合集标题）。如需彻底消除需补入库层 symbol_name。
